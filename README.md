*Características del Sistema
1) Inicio de sesión con usuario y contraseña.
2) Roles de usuario: Dueño y Empleado.
3) Registro y administración de usuarios.
4) Registro de productos.
5) Control de stock de productos.
6) Registro de ventas.
7) Asociación de ventas a vendedores mediante código identificador.
8) Registro de clientes y empresas.
9) Registro de proveedores.
10) Reportes básicos de ventas.
11) Consulta de productos y stock disponible.
12) Historial básico de ventas realizadas.
